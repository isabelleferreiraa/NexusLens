# 🏗️ Decisões de Arquitetura

## 10/07/2026

### Cenário

O projeto será desenvolvido em um contexto corporativo bancário.

**Motivo**

Representa um cenário próximo ao encontrado em instituições financeiras e permite demonstrar aplicações práticas de análise de grafos e Inteligência Artificial.

---

### Banco de Dados

Será utilizado PostgreSQL.

**Motivo**

Banco relacional amplamente utilizado em ambientes corporativos.

---

### API

Será utilizada FastAPI.

**Motivo**

Framework moderno, rápido e amplamente utilizado para APIs em Python.

---

### Grafos

Será utilizada a biblioteca NetworkX.

**Motivo**

Biblioteca consolidada para construção e análise de grafos.

---

### Inteligência Artificial

A IA será responsável apenas pela interpretação dos dados e geração do relatório.

Todos os cálculos e métricas serão realizados pelo backend.

**Motivo**

Separação de responsabilidades entre lógica de negócio e Inteligência Artificial.

---

### Front-end

Será desenvolvido utilizando React + TypeScript.

**Motivo**

Tecnologias amplamente utilizadas em aplicações modernas e corporativas.
